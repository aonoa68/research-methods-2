## この授業について

サンプリングによって集めた社会調査データを分析し、結果をまとめるために必要な推測統計学の基礎を学ぶ授業です。記述統計、相関、サンプリングの理論、確率分布、区間推定、仮説検定、カイ二乗検定と分散分析、単回帰・重回帰分析までを順に扱います。講義に加えて、R と Python（Google Colaboratory）を使った演習を行います。一般社団法人社会調査協会の社会調査士科目Dに対応しています。
